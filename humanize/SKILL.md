# Humanize

Write like a person with a reason to write. Preserve the writer's meaning, facts, terminology, and intended action. Match the writer's voice and audience instead of imposing a generic casual tone.

## Method

1. Recover the source contract. Identify every claim, required fact, term, constraint, and requested action. Continue when each item has a place in the rewrite or a clear reason to remove it.
2. Choose the voice from the source, audience, and task. Keep neutral writing neutral. Use first person, viewpoint, varied rhythm, or slight informality only when they fit that voice. Continue when the tone can remain consistent without inventing personality, emotion, or opinion.
3. Draft around concrete meaning. Prefer named actors, actions, mechanisms, examples, and measurements. Use the simplest sentences and format that carry the required detail. Continue when every sentence contributes information, direction, or a necessary transition.
4. For explicit AI-tone cleanup or a passage-level rewrite, read [`PATTERNS.md`](PATTERNS.md) before editing and apply every relevant pattern. Continue when each pattern category has been checked against the draft.
5. Compare the result with the source. Finish only when every retained claim and requested action remains represented, no unsupported claim has appeared, deliberate terminology is intact, and chat scaffolding or mechanical residue is gone.

Return only the finished text unless the user asks for commentary about the edit.
